Hi-Horizon Racing Team

Hi-horizon racing team is a hobby project me and friends from highschool work on. We build a one person solar powered boat, in which we perform races each year at Akkrum in the Netherlands and at Balaton in Hungary. The team has been founded in 2019 and for me this was a great place to learn some practical skills in webdev, embedded and even some electrical design.

Battery

One of the biggest projects for me was the battery. This 60V li-ion battery is a 1.5 Kwh buffer for when the sun is not shining as much. I did a large part of the electrical design. which involved creating PCBs for precharge, power distribution and other control signals. But also choosing components such as relays and dc-converters. On the software side, I programmed the BMS firmware, making sure the control circuits go on and off correctly.

Embedded telemetry

Part of my work is the Embedded telemetry systems placed onboard. The goal is to gather data which serves as information to the pilot as well as use the data in our racing strategy.
We gather data from a lot of different sensors and components, such as the battery, ESC, GPS and so on. The telemetry system logs data to an SD card, displays information to the pilot and sends data to land so we can monitor it for strategy.

Telemetry Dashboard

The dashboard for viewing the boat data was one of my earliest responsibilities. I did a few revisions, going from PHP website to Svelte and ending up making a Svelte + Tauri application. The Dashboard connects with the boat through MQTT and in the future should also be able to connect with a SocketCan device.
